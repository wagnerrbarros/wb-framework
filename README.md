# wb-framework

Estrutura conceitual e teórica para modelagem de conhecimento baseada em estratos, dialetos e manuais aplicados.

## Repositórios

| Subprojeto | Descrição |
|-----------|-----------|
| **wb-dialect** | Definição formal da linguagem de especificação (mestrado) |
| **wb-strata** | Fundamentação teórica dos estratos de conhecimento (doutorado) |
| **wb-manual** | Caso de estudo aplicado da metodologia |
