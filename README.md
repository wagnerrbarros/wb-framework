# WB Framework

**A cognitive-philosophical framework for human autonomy, formalized in a
human-AI specification language.**

[![License: CC BY-SA 4.0](https://img.shields.io/badge/License-CC%20BY--SA%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-sa/4.0/)

---

## What is this?

WB Framework is an integrated body of work that spans philosophy,
neuropsychology, game theory, and human-AI interaction. It was born
from a personal need: how does a neurodivergent mind operate
effectively in a world that wasn't designed for it?

The answer turned out to be three things:

1. **A language** — to structure cognitive knowledge so that humans
   and machines can collaborate on it.
2. **A philosophy** — to explain why humans act against their own
   interests and what to do about it.
3. **An operating system** — to translate all of that into daily
   executable rules.

## How to Use

**If you're a researcher:**
Start with [wb-dialect](./wb-dialect) — the specification language.
Then read [wb-strata](./wb-strata) for the theoretical framework
and [wb-manual](./wb-manual) for the applied case study.

**If you're neurodivergent and looking for structure:**
Start with [wb-manual](./wb-manual). Adapt the decision engine and
protocols to your own profile. Use WB-Dialect to formalize your
own cognitive operating system.

**If you're a developer building AI tools:**
Start with [wb-dialect](./wb-dialect). The design principles and
file structure specification are directly applicable to any system
that needs to process structured human cognitive input.
