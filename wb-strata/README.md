## What is Strata?

Strata is a philosophical framework that integrates **existentialism**,
**game theory**, and **practical philosophy** to address a fundamental
problem:

> *Why do humans systematically act against their own interests,
> even when they know better — and what can they do about it?*

Classical game theory models agents as rational maximizers.
Existentialist philosophy describes how individuals deny their own
freedom. Behavioral economics documents cognitive biases. **No existing
framework formally integrates all three into a practical decision tool.**

Strata does.

## Core Innovation: Lastro (Ballast)

The central concept of Strata is **lastro** — the capacity to sustain
refusals without collapse.

Unlike related concepts:

| Concept | Source | Dimensionality |
|---|---|---|
| BATNA | Fisher & Ury (1981) | Single (best alternative) |
| Outside option | Rubinstein (1982) | Single (negotiation alternative) |
| **Lastro** | **Strata** | **Multidimensional** |

Lastro operates across four dimensions:

| Type | Description |
|---|---|
| **Financial** | Resources to survive without accepting unfavorable conditions |
| **Temporal** | Time horizon allowing strategic patience |
| **Reputational** | Social capital that opens alternatives |
| **Cognitive** | Mental capacity to evaluate and decide clearly |

## The Four Layers

| Layer | Name | Function |
|---|---|---|
| C3 | Identity Construction | Consolidate self through repeated choices |
| C2 | Strategic Decision | Choose with expanded time horizon |
| C1 | Game Mapping | Identify active games, rules, payoffs |
| C0 | Lastro | Eliminate immediate coercion |

Each layer has:
- A specific **objective**
- A **success criterion**
- Identified **risks**

## Operational Rules

| ID | Rule |
|---|---|
| **R001** | Never play the purpose game without winning the ballast game |
| **R002** | If you cannot say no, there was no choice |
| **R003** | Every relevant choice alters the future space of possible games |
| **R004** | Money is not an end — it is a structural variable |

## Decision Process (Standard)

```
INPUT: context + lastro level + available games
↓
PROCESS: 1. Identify coercion
         2. Classify time horizon
         3. Evaluate impact on lastro
         4. Simulate irreversibility
         5. Check for jouissance or bad faith
↓
OUTPUT: decision + cost assumed + expected gain + lastro impact
```

## Scope

**Covers:**
- Structured decision-making under real-world constraints
- Progressive autonomy building
- Recognition of unconscious patterns (jouissance, bad faith)

**Does not cover:**
- Therapeutic intervention
- Guaranteed outcomes
- Events beyond individual control

## Status

**Experimental (v0.1.1).** This framework has been applied in personal
cognitive management (see [The Manual](https://github.com/wb-framework/wb-manual))
but has not yet been formally validated in controlled empirical settings.
