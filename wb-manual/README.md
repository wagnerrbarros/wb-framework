## What is The Manual?

The Manual is a **cognitive operating system** — a structured set of
decision rules, execution protocols, failure recovery mechanisms, and
psychological confrontation tools — designed for an individual with
**Autism Spectrum Disorder (Level 1)** to operate effectively in
real-world conditions.

It translates a neuropsychological assessment into an **executable
architecture** using [WB-Dialect](https://github.com/wb-framework/wb-dialect)
as its specification language.

## Architecture

| Module | Function |
|---|---|
| **Core Architecture** | Defines operating mode (deep hyperfocus, monotasking) |
| **Primary Asset** | Identifies and protects the main cognitive resource |
| **Decision Engine** | 5 formal rules for evaluating and rejecting actions (DEC-001 to DEC-005) |
| **Prospection Engine** | Architecture of opportunity — maps problems, signals clarity |
| **Execution Engine** | 4-phase model: Diagnosis → Modeling → Implementation → Finalization |
| **Completion Protocol** | Prevents abandonment after the modeling phase |
| **Monetization Engine** | Converts generated value into captured value |
| **Degraded Mode** | Minimum viable operation under low energy |
| **Failure Protocols** | Recovery procedures for overload, indecision, abandonment |

## Theoretical Foundations

The Manual integrates four theoretical streams as **operational tools**
(not therapeutic goals):

| Stream | Concept | Operational Use |
|---|---|---|
| **Neuropsychology** | ASD Level 1 | Deep focus as asset; social improvisation as cost center |
| **Psychoanalysis** | Jouissance (Lacan) | Naming the "almost" pattern to break the loop |
| **Existentialism** | Bad faith (Sartre) | Recognizing inaction as choice, not condition |
| **Systems Theory** | State machines, fallback protocols | Degraded modes, failure recovery |

### Key Operational Definitions

- **Goce (Jouissance):** Paradoxical pleasure from the "almost" position —
  almost sold, almost recognized. Once named, it loses power to govern
  behavior unconsciously.

- **Alibi:** Internal narrative that justifies inaction and substitutes
  real identity. Example: "I can't sell" when the truth is "I choose
  not to sell." Equivalent to Sartrean bad faith.

- **Ato Analítico:** Acting despite jouissance, without using resistance
  as a precondition.

- **Ato Neurótico:** Postponing action until resistance is "overcome" —
  which never happens.

## Decision Engine

| ID | Rule | Logic |
|---|---|---|
| DEC-001 | Primary Asset Filter | If activity does not use verbal-conceptual modeling → REJECT |
| DEC-002 | Cost-Return Ratio | If cognitive cost > expected return → REJECT |
| DEC-003 | Minimum Clarity | If problem is unstructured → STRUCTURE before acting |
| DEC-004 | Leverage | Prioritize activities with multiplicative effect |
| DEC-005 | Money Required | If no clear monetization path → LOW PRIORITY |

## Degraded Mode

Reduced capacity is treated as a **valid operational state**, not a
failure:

| Trigger | Minimum Viable Actions |
|---|---|
| Cognitive overload | Organize information (CRM, spreadsheet) |
| Low energy | Register ideas (no sales commitment) |
| Chaotic environment | Execute mechanical tasks (post-call checklist) |
| | Post ready-made offers (no improvisation) |

## Mapa do Goce (Template)

A structured self-confrontation tool:

1. **The scene that fixed the jouissance** — describe the traumatic situation
2. **What the Other said** — the word that defined identity
3. **What I decided in that moment** — never expose? never ask?
4. **How this pattern repeats today** — sales, relationships, commitments
5. **What happens in the body when I'm about to act** — cold, paralysis, discharge
6. **The minimum viable act for today** — 1 message with price to 1 stranger

## Scope

**Covers:**
- Translating ASD Level 1 neuropsychological profile into executable rules
- Decision-making under cognitive constraint
- Confronting unconscious patterns of professional inaction
- Monetization strategies adapted to neurodivergent cognition

**Does not cover:**
- Replacement of clinical or therapeutic support
- Generalization to other neuropsychological profiles without adaptation
- Guaranteed commercial outcomes
